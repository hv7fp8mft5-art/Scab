SCAB 2 — GitHub Pages / iPhone

1. Create a free GitHub account at github.com if needed.
2. Create a new repository, e.g. SCAB2. Public is simplest for GitHub Pages.
3. Upload ALL files in this folder to the repository root:
   - index.html
   - manifest.webmanifest
   - .nojekyll
4. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
5. Wait for deployment. GitHub will show the site URL.
6. Open that URL in Brave or Safari on the iPhone.
7. Safari: Share -> Add to Home Screen.

LIVE DATA
The app calls Open-Meteo, Nominatim/OpenStreetMap and OSRM directly from the browser. An internet connection is required. Browser/network policies can affect third-party feeds.

AUSTRALIA
BOM links are provided for marine warnings, marine forecasts and official tide predictions. Modelled sea-level data must not be treated as an authoritative navigation tide.

SAFETY
This is a planning aid, not a substitute for official warnings, charts, navigation equipment, local knowledge, emergency procedures or the responsible authority/OIC.
